  4. go doc before Google. Try go doc strings.Builder in your terminal right now.
  5. Tick units off as you finish them — the grid at the top left fills in. Progress saves in this browser.

go mod init <path>              go mod tidy

# testing & performance
go test -run TestName -v ./pkg  go test -bench=. -benchmem -count=10
go tool cover -html=cover.out   benchstat old.txt new.txt
go tool pprof cpu.out           dlv debug ./cmd/server

# security
